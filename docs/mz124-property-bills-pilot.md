# MZ-124 房源账单回归样板

## 验收边界

- 用 Git 固定版本的 Next 房源代付页面和房源账单组件、实际房源账单路由、实际权限中间件/权限表和临时 PostgreSQL；不是静态网页，也不是拦截并返回写入成功。
- 本地身份入口注入两种合成身份，不是线上登录或账号会话。房源代付待处理、日历、通知等非目标区域不参与验收。数据库是本次运行创建的最小测试结构，不是共享 Dev 或生产库，也不是全量迁移验证。
- 浏览器只允许两个指定本地来源，后端仅连接 127.0.0.1 的独立数据库，不加载业务环境文件，不启动同步、发信、通知或正式部署。失败不会尝试线上地址。
- 基础数据：两个测试房源，同类两份代付模板和一笔历史账单。取消、保存、停用、恢复、只读拒绝均以实际页面及独立读回取证。暂停期间的账单生成条件继续沿用现有 FR-050 底层测试，浏览器不触发正式生成任务。
- 结果记录不代表共享 Dev 的登录和实时配置通过，不代表 GitHub 分支保护已经生效。

## 本机重复运行

需要已有 Node、对应锁文件的已安装依赖、Playwright Chromium、initdb/pg_ctl/psql，不安装依赖、不建 Docker。允许本机 PostgreSQL 共享内存、本机连接和 Chromium。运行脚本不读取业务 .env，不使用现有任何数据库。

```sh
bash scripts/mz124-bills-pilot-run.sh /path/to/root-checkout 83e26c9
```

测试先以错误的历史对照验证浏览器断言必失败并且不产出通过结果，再用正确数据跑全套。验收器拒绝没有结果或缺关键步骤的回执。遇到监听端口被占用会退出，不停止无关服务。结束关闭本次创建的临时进程；仅保留本机临时证据和截图。底层测试沿用原仓库 backend 的 `npm run test:mz128-property-bills`。
